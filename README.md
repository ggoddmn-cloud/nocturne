# Nocturne Video — Telegram Bot

Перенос Nocturne Video 2.0 на Telegram. Веб-сервер и HTML больше не нужны.

## Windows 10/11
1. Установи Python 3.11+ (с Python Launcher и Add to PATH).
2. Создай бота в @BotFather командой /newbot, сохрани токен.
3. Скопируй `.env.example` в `.env` (имя без `.txt`). Впиши BOT_TOKEN=твой_токен.
4. Запусти `start_windows.bat`. При первом запуске устанавливаются зависимости и Deno. Напиши боту /id.
5. Останови процесс Ctrl+C, впиши полученный числовой ID в ALLOWED_USER_IDS в `.env`, запусти снова.
6. Напиши /start, отправь ссылку, нажми кнопку качества. Бот отправит исходный файл как документ без дополнительного сжатия Telegram.

## Linux/macOS
Те же настройки `.env`, затем `chmod +x start_mac_linux.sh && ./start_mac_linux.sh`. Для Linux может понадобиться пакет python3-venv. Для обновления зависимостей: `.venv/bin/python -m pip install -U -r requirements.txt` (Windows: `.venv\Scripts\python.exe -m pip install -U -r requirements.txt`).

## Настройки
- BOT_TOKEN — секретный токен. Не публикуй .env.
- ALLOWED_USER_IDS — числовые ID через запятую; пустой список не разрешает скачивание никому.
- MAX_FILE_MB — лимит файла, по умолчанию 49 MB; не увеличивай при использовании облачного Bot API.

## Команды
/start, /help — меню; /id — ID; /status — статус; /cancel — отмена выбора качества (не остановка уже начатого скачивания).

## Особенности и ограничения
- Сохраняется логика yt-dlp, FFmpeg, Deno, HLS и выбора качества исходника. Предпросмотр заменён ссылкой на оригинал и метаданными.
- Два параллельных задания, одно на пользователя. Кнопки действуют 30 минут, после перезапуска выбор сбрасывается. Временные файлы удаляются после завершения или ошибки.
- Файлы больше лимита не отправляются, выбери меньшее качество. Нет автоматического перекодирования или локального Bot API.
- YouTube/TikTok могут ограничивать доступ. Не используются cookies из браузера и обход авторизации. Скачивай только разрешённый контент.
- Только личные чаты и доверенные пользователи. Проверка URL не является полной защитой от SSRF через внешние загрузчики, HLS или DNS rebinding. Не открывай бота публично; на VPS изолируй процесс и запрети доступ к внутренним сетям и metadata endpoints на уровне сети. Лимит размера не заменяет дисковые квоты. При аварийной остановке возможны оставшиеся временные папки nocturne_*.
- Бот работает пока запущен процесс и есть интернет. Для VPS можно использовать systemd или другой менеджер процессов. Не запускай две копии с одним токеном.
- Проверено: компиляция Python и локальные тесты ядра. Реальная отправка в Telegram и скачивание с платформ не проверены без токена и сетевого доступа.
